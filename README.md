# Remix of Moonlight Radiance to T.A BEAUTY STUDIO

You are a senior product designer, UX designer and front-end engineer.

Design and build a world-class website for Moonlight Beauty Salon.

The website should feel elegant, luxurious, feminine and modern.

DO NOT generate a generic AI website.

The design quality should rival premium beauty brands and luxury hotel websites.

The overall feeling should be calm, premium, soft and sophisticated.

Use the existing Moonlight Beauty Salon logo and build the entire visual identity around its colors.

Extract the soft nude, beige, blush, warm cream and muted taupe colors from the logo.

Avoid bright colors.

Avoid heavy shadows.

Use subtle gradients.

Rounded corners.

Beautiful spacing.

Minimal design.

Large photography.

Micro animations.

Smooth transitions.

Soft hover effects.

Elegant typography.

The entire experience should feel expensive.
